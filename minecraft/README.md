# Minecraft build scripts

Bu klasör, Paper ve Velocity için kurulum ve build betiklerini içerir.

## Dizin yapısı

```text
minecraft/
├── README.md
├── .gitignore
└── scripts/
    ├── setup-paper-1.21.1.sh
    ├── setup-paper-1.21.11.sh
    ├── setup-velocity-4.0.0.sh
    └── build-all.sh
```

## Kullanım

```bash
cd Sw-lerim
./minecraft/scripts/setup-paper-1.21.1.sh
./minecraft/scripts/setup-paper-1.21.11.sh
./minecraft/scripts/setup-velocity-4.0.0.sh
```

İstersen tek komutta hepsini kur:

```bash
cd Sw-lerim
./minecraft/scripts/build-all.sh
```
